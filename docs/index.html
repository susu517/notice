识别网址

贴一个通知文章链接，自动抓正文并按同一套口径提炼。走 GitHub 抓取，大约等 1 分钟。

抓不到正文时会显示抓到了多少字，方便判断是链接不对还是正文在附件里。

推送邮箱

填一次就行。之后点每条通知右上角的「推送」，手机会直接打开邮件 App，标题和内容都已经填好，按发送即可。不需要申请 GitHub Token。

只存在这台手机里，不会写进网页。

推送

邮件推送：每 30 分钟检查一次，有新的重要通知才发信，没有新通知不发。

收件邮箱和发件邮箱在 GitHub 仓库的 Settings → Secrets 里配置（SMTP_USER / SMTP_PASS / MAIL_TO）。

导出备份

把留档库里所有数据存成一个 JSON 文件。换手机、清浏览器、或者手滑清空之后，靠这个文件能把标题、分类、时间、要点、原文链接都找回来。

浏览器会把它存到手机的「下载」目录。

监视范围

正在监控的网址在「常用网址」板块，那里也能直接加新栏目。

新加的栏目第一次检查只登记已有通知，不推送历史，从第二次才开始推新的。

留档与删除

数据存在仓库的 data/notices.json 里，每次抓完自动提交，不会丢。

留档库的「删除」只是移进回收站（本地记录）；回收站的「彻底删除」会同时把这条从仓库的 data/notices.json 里删掉，之后不会再出现。

彻底删除需要 Token 勾上 Contents: Read and write 权限；没填 Token 时只在本机隐藏。
